# CompAdapt

Project page for **CompAdapt: Adaptable Composite Motion Modeling for Physics-Consistent Text-to-Video Generation** (arXiv preprint, 2026).

This repository hosts the static project website (GitHub Pages):
- `index.html` is the site entry; `.nojekyll` disables Jekyll processing.
- Videos and figures are served as static files under `example*.mp4`, `compare_*/`, and `assets/`.

Authors: Haoran Qin, Renlong Wu, Tianyu Huang, Yukang Ding, Hui Li, Wangmeng Zuo.
